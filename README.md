## 🎮 Fonctionnalités
- **Niveau 1** : Placement des composants sur une carte mère (Drag & Drop)
- **Niveau 2** : Architecture de Von Neumann (UC, UAL, Mémoire, Entrée/Sortie)
- **Niveau 3** : Quiz interactif (8 questions avec corrections détaillées)
- Score en temps réel, déblocage progressif, design responsive & tactile

## 🛠️ Technologies
HTML5 • CSS3 • JavaScript Vanilla • GitHub Pages

## ▶️ Comment jouer
1. Ouvrir le lien GitHub Pages
2. Glisser-déposer les composants dans les zones prévues
3. Valider avec le bouton "Vérifier"
4. Progresser vers le quiz final

> ✅ Aucun plugin ou installation requise. Compatible mobile/desktop.
